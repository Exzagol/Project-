ระบบประเมินโปรเจกต์และคะแนนรายวิชา
====================================

ไฟล์ในโฟลเดอร์นี้
  index.html, style.css, script.js, sync-core.js   ตัวระบบ (ต้องอยู่โฟลเดอร์เดียวกัน)
  vendor/                            ไลบรารีอ่านไฟล์ PDF (pdf.js)
  assets/                            รูปพื้นหลังเบลอ 2 แบบ (สว่าง/มืด) -- ฝังอยู่ใน style.css แล้ว เก็บไว้เผื่อนำไปใช้ต่อ
  server.js                          เซิร์ฟเวอร์: ส่งไฟล์เว็บ + เก็บข้อมูลกลางให้ทุกเครื่องใช้ร่วมกัน
  data/                              (สร้างเองตอนเปิดเซิร์ฟเวอร์) db.json = ข้อมูลทั้งหมด · backups/ = ไฟล์สำรองอัตโนมัติ · secret.key = กุญแจล็อกอิน
  start-server.bat / start-tunnel.bat  ดับเบิลคลิกเปิดเซิร์ฟเวอร์ / เปิดลิงก์ Cloudflare (Windows)

วิธีเปิดใช้งาน (เครื่องตัวเอง)
  1. แตกไฟล์ zip ไว้ในโฟลเดอร์เดียวกัน
  2. ดับเบิลคลิก start-server.bat (ต้องติดตั้ง Node.js ก่อน ดูขั้นที่ 1 ด้านล่าง) แล้วเปิด http://localhost:3000
     (แนะนำ Chrome หรือ Edge รุ่นใหม่) ข้อมูลจะเก็บที่เซิร์ฟเวอร์ (ไฟล์ data/db.json) ทุกเครื่องเห็นข้อมูลชุดเดียวกัน
     ถ้าดับเบิลคลิก index.html หรือใช้ Live Server ระบบยังทำงานได้ แต่เป็น "โหมดเครื่องเดียว"
     คือเก็บข้อมูลในเบราว์เซอร์เครื่องนั้นเหมือนรุ่นเก่า ไม่ซิงก์กับเครื่องอื่น
  3. เปิดครั้งแรกจะให้ตั้งค่าแอดมิน (ครู) แอดมินมีได้คนเดียว
     (โหมดเซิร์ฟเวอร์: ตั้งค่าครั้งแรกได้เฉพาะบนเครื่องที่รัน server.js คือเปิด http://localhost:3000 บนเครื่องนั้น)

ลำดับการใช้งานที่แนะนำ (แอดมิน)
  1. รายชื่อนักเรียน  -> ลากไฟล์ PDF หรือ Excel (.xlsx) ใบรายชื่อมาวาง ระบบอ่าน เลขที่ / เลขประจำตัว / ชื่อ-สกุล
                        ถ้าไฟล์ไม่มีระดับชั้น ให้เลือก ปวช./ปวส. ที่ช่อง "ถ้าไม่มีระดับชั้นในไฟล์ ให้ใช้"
                        ชื่อหรือเลขประจำตัวที่ซ้ำจะไม่ถูกเพิ่มใหม่
  2. เกณฑ์โปรเจกต์    -> เพิ่มเกณฑ์และคะแนนเต็ม
  3. ครูที่ปรึกษา     -> เพิ่มบัญชี (ชื่อผู้ใช้ + รหัสผ่านชั่วคราว) ครูจะพิมพ์ชื่อจริงเองตอนเข้าครั้งแรก
  4. ผู้ใช้งาน        -> เพิ่มบัญชีผู้ประเมิน แล้วให้ "ยศ" (เช่น กรรมการโปรเจกต์) เหมือนให้ยศในดิสคอร์ด
                        ผู้ประเมินพิมพ์ชื่อจริงเองตอนเข้าครั้งแรก
  5. กลุ่มโปรเจกต์    -> พิมพ์ชื่อโปรเจกต์ไทย/อังกฤษ เลือกครูที่ปรึกษา และเลือกสมาชิกจากรายชื่อนักเรียน
                        (กลุ่มที่เพิ่งสร้างใหม่จะอยู่บนสุดเสมอ)
  6. รายวิชา          -> สร้างวิชา โยนไฟล์รายชื่อเข้าวิชา เพิ่มงาน แล้วกรอกคะแนนในตารางแบบกระดาษเช็คชื่อ (พิมพ์/บันทึกเป็น PDF ได้)

หน้าของแต่ละคน
  - ผู้ประเมิน    : เลือกโปรเจกต์ (กลุ่ม) -> ให้คะแนนตามเกณฑ์ทั้งกลุ่ม -> เขียนข้อเสนอแนะ
                    ประเมินเป็นกลุ่ม ไม่ใช่รายบุคคล (✓ หน้าชื่อโปรเจกต์ = ประเมินกลุ่มนั้นแล้ว)
  - ครูที่ปรึกษา  : เห็นเฉพาะโปรเจกต์ที่แอดมินเลือกตัวเองเป็นที่ปรึกษา (คะแนนเฉลี่ยของกลุ่ม + ข้อเสนอแนะ) และเขียนข้อเสนอแนะได้
  - แอดมิน        : เห็นทุกอย่าง ที่เมนู "คะแนนโปรเจกต์ทั้งหมด" เลือกดูได้ 2 แบบ
                      * ทุกคน           = ทุกกลุ่ม ตารางคะแนนของผู้ประเมินแต่ละคน + ค่าเฉลี่ยของกลุ่ม + ข้อเสนอแนะ
                      * เลือกผู้ประเมิน  = ดูทีละคน ว่าคนนั้นประเมินโปรเจกต์ไหนไปบ้าง ให้คะแนนเฉลี่ยเท่าไร กลุ่มนั้นมีใครบ้าง
                                          และมีโปรเจกต์ไหนที่ยังไม่ได้ประเมิน (เปลี่ยนไปดูอีกคนได้ทันที)

คะแนนเฉลี่ยคิดอย่างไร
  - คะแนนเฉลี่ยที่ผู้ประเมินให้กลุ่ม = ค่าเฉลี่ยของคะแนนทุกเกณฑ์ที่เขาให้แล้ว (เช่น 8 กับ 15 -> 11.50)
    คะแนนเต็มที่แสดงคือค่าเฉลี่ยของคะแนนเต็มของเกณฑ์เหล่านั้น (เช่น เต็ม 10 กับ 20 -> เต็ม 15)
  - คะแนนเฉลี่ยของกลุ่ม = เฉลี่ยทีละเกณฑ์จากผู้ประเมินทุกคนที่ให้แล้ว แล้วเฉลี่ยทุกเกณฑ์อีกครั้ง
  - ข้อมูลรุ่นเก่าที่เคยให้คะแนนรายนักเรียน ระบบแปลงให้อัตโนมัติ (เฉลี่ยคะแนนของสมาชิกในกลุ่มเป็นคะแนนของกลุ่ม)

หน้าตา
  - พื้นหลังเบลอสีพาสเทล (โหมดมืดจะเป็นโทนน้ำเงิน-ม่วง) การ์ดเป็นกระจกฝ้า
    รูปถูกฝังอยู่ใน style.css (ตัวแปร --bg-img-light และ --bg-img-dark) ถ้าอยากเปลี่ยนรูป แทนที่ค่า url(...) ตรงนั้น
  - ฟอนต์ Prompt (หัวข้อ/ปุ่ม) และ Sarabun (เนื้อหา) โหลดจาก Google Fonts ต้องต่ออินเทอร์เน็ตตอนเปิด
    ถ้าออฟไลน์จะใช้ฟอนต์ไทยของเครื่องแทน ระบบทำงานได้ปกติ


การเก็บข้อมูลที่เซิร์ฟเวอร์
-------------------------------------------------------
  * ข้อมูลทั้งหมด (ผู้ใช้ ยศ นักเรียน กลุ่ม เกณฑ์ คะแนน ข้อเสนอแนะ) เก็บในไฟล์ data/db.json ข้างๆ server.js
    ทุกเครื่องที่ล็อกอินเห็นข้อมูลชุดเดียวกัน แก้ที่เครื่องหนึ่ง เครื่องอื่นเห็นภายใน 2-3 วินาทีโดยไม่ต้องรีเฟรช
    ผู้ประเมินหลายคนกรอกคะแนนพร้อมกันได้ ระบบรวมให้ ไม่ทับกัน
  * ต้องล็อกอินก่อนจึงจะได้ข้อมูล เซิร์ฟเวอร์ตรวจสิทธิ์ทุกครั้งที่มีการแก้ (เช่น ผู้ประเมินแก้ได้เฉพาะคะแนนของตัวเอง
    คนที่ไม่ใช่แอดมินแก้บัญชีหรือยศไม่ได้) และไม่ส่งรหัสผ่านออกไปให้เบราว์เซอร์เลย ล็อกอินผิดซ้ำๆ จะถูกหน่วงชั่วคราว
  * ตั้งค่าแอดมินครั้งแรกได้เฉพาะบนเครื่องที่รัน server.js (เปิด http://localhost:3000) ผ่านลิงก์ Cloudflare ตั้งไม่ได้
    กันคนที่ได้ลิงก์ไปชิงเป็นแอดมินก่อนครู
  * สำรองข้อมูล: ระบบก๊อปไฟล์ไปไว้ที่ data/backups ให้เอง ตอนเปิดเซิร์ฟเวอร์ และทุก 30 นาทีที่มีการแก้ไข (เก็บ 40 ไฟล์ล่าสุด)
    แอดมินดาวน์โหลดไฟล์สำรองเองได้ที่เมนู "บัญชีของฉัน" > "ข้อมูลในระบบ" ควรเก็บไว้นอกเครื่องสักชุด (เช่น Google Drive / แฟลชไดรฟ์)
    ห้ามลบโฟลเดอร์ data ถ้ายังต้องการข้อมูล และไม่ควรส่งโฟลเดอร์ data ให้ใคร (มีรหัสผ่านที่เข้ารหัสแล้วและกุญแจล็อกอิน)
  * กู้ข้อมูล: ปิดเซิร์ฟเวอร์ > ก๊อปไฟล์จาก data/backups ไปทับ data/db.json > เปิดเซิร์ฟเวอร์ใหม่
    หรือเปิดเซิร์ฟเวอร์ที่ยังว่าง แล้วที่หน้า "ตั้งค่าระบบครั้งแรก" กด "เลือกไฟล์เพื่อนำเข้า" เลือกไฟล์สำรอง (.json)
  * ข้อมูลเดิมที่เคยเก็บในเบราว์เซอร์ (รุ่นก่อนมีที่เก็บข้อมูลบนเซิร์ฟเวอร์):
      - เปิด http://localhost:3000 ในเบราว์เซอร์ตัวเดิม ที่หน้า "ตั้งค่าระบบครั้งแรก" จะมีกล่อง "พบข้อมูลเดิม"
        กด "นำข้อมูลเดิมขึ้นเซิร์ฟเวอร์" แล้วล็อกอินด้วยบัญชีเดิม
      - ถ้าข้อมูลเดิมอยู่ที่อื่น (เช่น เปิดผ่าน Live Server พอร์ต 5502) ให้เปิดหน้านั้น ไปที่ "บัญชีของฉัน" > "ดาวน์โหลดไฟล์ข้อมูล (.json)"
        แล้วนำไฟล์มาเลือกที่หน้า "ตั้งค่าระบบครั้งแรก" ของเซิร์ฟเวอร์
      - นำเข้าได้เฉพาะตอนที่เซิร์ฟเวอร์ยังไม่มีข้อมูล และทำได้เฉพาะบนเครื่องที่รัน server.js
  * ถ้าปิดเครื่องหรือปิดหน้าต่างเซิร์ฟเวอร์ ผู้ใช้จะเห็นแถบแดง "ขาดการเชื่อมต่อกับเซิร์ฟเวอร์" ข้อมูลไม่หาย
    สิ่งที่แก้ค้างอยู่จะถูกส่งเองเมื่อเซิร์ฟเวอร์กลับมา (ถ้ายังไม่ได้ปิดหน้าเว็บ)
  * ถ้า server.js ขึ้นว่า "อ่านไฟล์ข้อมูลไม่ได้" แปลว่า data/db.json เสีย ให้ก๊อปไฟล์ล่าสุดจาก data/backups มาแทนที่


วิธีให้คนอื่นเข้าลองใช้ (server.js + Cloudflare Tunnel)
-------------------------------------------------------
server.js เป็น "ตัวส่งไฟล์เว็บ" และ "ที่เก็บข้อมูลกลาง" ของระบบ ส่วน Cloudflare Tunnel (แบบ Quick Tunnel)
จะเปิดทางจากอินเทอร์เน็ตมาที่เครื่องของเรา โดยไม่ต้องมีบัญชี Cloudflare และไม่ต้องตั้งค่า router

  ขั้นที่ 1  ติดตั้ง Node.js (ครั้งเดียว)
     ดาวน์โหลดรุ่น LTS จาก https://nodejs.org แล้วติดตั้ง จากนั้นเปิด Terminal / Command Prompt พิมพ์
        node --version
     ถ้าขึ้นเลขเวอร์ชัน แปลว่าพร้อมแล้ว

  ขั้นที่ 2  เปิดเซิร์ฟเวอร์
     ดับเบิลคลิก start-server.bat   (หรือเปิด Terminal ในโฟลเดอร์นี้แล้วพิมพ์  node server.js)
     จะขึ้นข้อความ "เซิร์ฟเวอร์ทำงานแล้ว" ลองเปิด http://localhost:3000 ในเบราว์เซอร์ให้เห็นหน้าระบบก่อน
     ถ้ายังไม่มีแอดมิน ให้ตั้งค่าครั้งแรกตรงนี้ (บนเครื่องนี้เท่านั้น) ก่อนจะเปิดลิงก์ให้คนอื่น
     (ถ้าอยากใช้พอร์ตอื่น  node server.js 8080)

  ขั้นที่ 3  ติดตั้ง cloudflared (ครั้งเดียว)
     Windows : เปิด Command Prompt หรือ PowerShell แล้วพิมพ์
                  winget install --id Cloudflare.cloudflared
               จากนั้นปิดแล้วเปิด Terminal ใหม่ ลองพิมพ์  cloudflared --version
     macOS   : brew install cloudflared
     Linux   : ดูวิธีที่ https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/

  ขั้นที่ 4  เปิดลิงก์ให้คนอื่นเข้า (เปิดหน้าต่างใหม่ ปล่อยหน้าต่างเซิร์ฟเวอร์ไว้)
     ดับเบิลคลิก start-tunnel.bat   (หรือพิมพ์  cloudflared tunnel --url http://localhost:3000)
     รอสักครู่ จะมีกรอบข้อความแสดงลิงก์หน้าตาแบบนี้
        https://ชื่อสุ่มหลายคำ.trycloudflare.com
     ก๊อปลิงก์นี้ส่งให้เพื่อนได้เลย

  ขั้นที่ 5  ปิด
     กด Ctrl+C ทั้งสองหน้าต่าง ลิงก์จะใช้ไม่ได้ทันที

ข้อควรรู้ (สำคัญ)
  * ข้อมูลของระบบเก็บที่เซิร์ฟเวอร์ (data/db.json) ทุกคนที่เปิดลิงก์และล็อกอินจะเห็นข้อมูลชุดเดียวกัน
    แอดมินสร้างบัญชีให้ผู้ประเมินแล้วส่งชื่อผู้ใช้ + รหัสผ่านชั่วคราวให้ ผู้ประเมินเปิดลิงก์เข้ามาล็อกอินได้เลย
    ถ้าปิดคอมพิวเตอร์หรือปิดหน้าต่างเซิร์ฟเวอร์ คนอื่นจะเข้าไม่ได้ชั่วคราว (ข้อมูลไม่หาย)
  * ถ้าส่งลิงก์ให้คนที่ไม่ไว้ใจ อย่าลืมว่าใครก็เปิดหน้าล็อกอินได้ แต่ต้องมีชื่อผู้ใช้/รหัสผ่านจึงจะเห็นข้อมูล
    ใช้รหัสผ่านชั่วคราวที่เดายาก (ระบบสุ่มให้ 8 ตัว) และเลิกใช้บัญชีที่ไม่ต้องการแล้ว
  * ลิงก์ trycloudflare.com เปลี่ยนใหม่ทุกครั้งที่เปิด และใช้ได้เฉพาะตอนที่เปิดคอมพิวเตอร์ กับเปิดทั้งสองหน้าต่างค้างไว้
    Cloudflare ให้ Quick Tunnel ไว้ใช้ทดสอบ ไม่รับประกันว่าจะใช้งานได้ตลอด
  * ถ้าเครือข่ายโรงเรียนบล็อกการเชื่อมต่อ ให้ลองสั่งแบบนี้แทน
        cloudflared tunnel --protocol http2 --url http://localhost:3000
  * ถ้าในเครื่องมีไฟล์ตั้งค่า cloudflared อยู่แล้ว (ที่ ~/.cloudflared/config.yaml) Quick Tunnel อาจทำงานผิดปกติ
    ให้ย้ายไฟล์นั้นออกไปชั่วคราว
  * ในอนาคตถ้าจะขึ้น host จริง: ต้องเป็นโฮสต์ที่รัน Node.js ได้ (เช่น VPS, Render, Railway) อัปโหลดทั้งโฟลเดอร์แล้วรัน node server.js
    และต้องให้โฟลเดอร์ data อยู่บนดิสก์ถาวร (ถ้าโฮสต์ล้างดิสก์ทุกครั้งที่รีสตาร์ท ข้อมูลจะหาย)
    การตั้งค่าแอดมินครั้งแรกบนโฮสต์: ตั้งตัวแปร ALLOW_REMOTE_SETUP=1 ชั่วคราวเฉพาะตอนตั้งค่าครั้งแรก แล้วเอาออก
    (โฮสต์ไฟล์นิ่งอย่าง GitHub Pages / Netlify ใช้ได้เฉพาะโหมดเครื่องเดียว ข้อมูลจะไม่ซิงก์)


ข้อควรรู้ทั่วไป
  - โหมดเซิร์ฟเวอร์ (เปิดผ่าน server.js): ข้อมูลทั้งหมดเก็บที่เซิร์ฟเวอร์ ซิงก์ข้ามเครื่องภายใน 2-3 วินาที
    (แอดมินแก้ ผู้ประเมินเห็นทันทีโดยไม่ต้องรีเฟรช) ล็อกอินค้างไว้ในแท็บนั้นจนกว่าจะปิดแท็บหรือกด "ออกจากระบบ"
  - โหมดเครื่องเดียว (ดับเบิลคลิก index.html / Live Server): ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้ (localStorage)
    ถ้าล้างข้อมูลเบราว์เซอร์ ข้อมูลในระบบจะหาย และซิงก์ได้เฉพาะแท็บในเบราว์เซอร์เดียวกัน (ดาวน์โหลดไฟล์ข้อมูลเก็บไว้ได้ที่ "บัญชีของฉัน")
  - PDF บางไฟล์ทำสระ "ำ" ในชื่อหาย (เช่น สำราญ เป็น สาราญ) ถ้ามีไฟล์ Excel ให้ใช้ Excel
    ถ้านำเข้า PDF ไปแล้ว ให้นำเข้า Excel ซ้ำ ระบบจะแก้ชื่อให้ตามเลขประจำตัว
